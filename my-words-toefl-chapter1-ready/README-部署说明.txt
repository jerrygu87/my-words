情景背词 - 托福第一章部署说明

已完成页面：
1. index.html        首页，托福专区可点击
2. toefl.html        托福故事列表
3. reader.html       第一章互动阅读页
4. wordbook.html     本地单词本

主要功能：
- 第一章完整故事，共100个重点词
- 点击重点词定位到词卡
- 浏览器英文发音
- 加入/移除单词本
- 单词状态：新加入、学习中、已掌握
- 隐藏中文释义、隐藏重点词、字体大小调整
- 自动保存阅读位置
- 原PDF和原稿图片对照
- 手机和电脑自适应

部署到 Cloudflare Pages（直接上传）：
1. 解压本压缩包。
2. 登录 Cloudflare 控制台。
3. 打开 Workers & Pages。
4. 进入原来的 my-words 项目。
5. 选择创建新部署/上传资产。
6. 上传“解压后的项目文件夹中的全部文件”，不要只上传压缩包。
7. 等待部署完成后刷新网站。

重要：
- 请保留 assets/chapter1.pdf 和页面中的原作者署名、版权提示。
- 单词本当前保存在浏览器 localStorage 中；换设备不会自动同步。

内容说明：互动阅读文字依据上传PDF第1-6页整理；原稿中“继续嘲切”等用字按原文件保留，原PDF可随时对照。
